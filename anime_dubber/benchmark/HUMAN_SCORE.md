# HUMAN_SCORE.md — Subjective Quality Scoring

Для каждой генерации (`benchmark/results/<model>/<line_id>.wav`) заполни оценку от 0 до 4.

## Шкала

| Score | Значение |
|---|---|
| 0 | Плохо: AI-голос, без эмоций, акцент, искажения |
| 1 | Терпимо: похоже на речь, но явно синтетика |
| 2 | Хорошо: живой голос, но что-то смущает |
| 3 | Очень хорошо: трудно отличить от человека |
| 4 | Отлично: не отличить от оригинального актёра озвучки |

## Категории

Поставь оценку по каждой:

| Категория | Описание | Оценка |
|---|---|---|
| **naturalness** | Общее впечатление: естественная речь vs синтетика | 0-4 |
| **speaker_similarity** | Насколько голос похож на reference.wav | 0-4 |
| **russian_pronunciation** | Произношение русских слов, ударения, интонации | 0-4 |
| **emotion_match** | Соответствие заявленной эмоции (neutral/happy/sad/angry) | 0-4 |
| **whisper** | Качество шепота (для whisper_* реплик) | 0-4 |
| **shout** | Качество крика (для shout_* реплик) | 0-4 |
| **laugh** | Качество смеха (для laugh_* реплик) | 0-4 |
| **cry_realism** | Реалистичность плача (для cry_* реплик) | 0-4 |
| **gasp** | Качество аха/вдоха (для gasp_* реплик) | 0-4 |
| **overall** | Общее впечатление от линии | 0-4 |

## Заметки

`HUMAN_SCORE.md` (этот файл) - ручная разметка.
`benchmark_results.json` - авто-метрики (RTF, VRAM, sample_rate, duration).

НЕ ставь оценки пока не послушал output. Особенно для `cry_*` и `shout_*` - тег "cry_realism" в файле НЕ гарантирует что плач звучит убедительно.
